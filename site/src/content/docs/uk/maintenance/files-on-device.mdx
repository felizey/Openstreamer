Для щоденного користування нічого з цього не потрібно: усе є у
вебінтерфейсі. Це для резервних копій, усунення несправностей і для всіх, хто
працює через [SSH](/docs/network/security).

## Налаштування: `/etc/openstreamer/`

| Файл                         | Що це                                                            |
| ---------------------------- | ---------------------------------------------------------------- |
| `settings.json`              | Усі налаштування, як їх завантажує **Export settings**           |
| `auth.json`                  | Пароль вебінтерфейсу (хешований) і ключ, яким підписуються входи |
| `overlay.png`                | Логотип для відео                                                |
| `splash-image`               | Власне зображення заставки, якщо його завантажено                |
| `settings.before-reset.json` | Налаштування, якими вони були до останнього скидання             |
| `settings.v<N>.json`         | Копія, що зберігається, коли оновлення змінює формат налаштувань |
| `image`                      | Позначає встановлення з готового образу                          |

<Admonition type="warning">
  Перш ніж редагувати `settings.json` вручну, зупини Openstreamer (`sudo systemctl
  stop openstreamer`), інакше він може перезаписати твої зміни. Файл, який не
  вдається прочитати, ігнорується, і Openstreamer запускається зі стандартними
  налаштуваннями.
</Admonition>

## Записи й оновлення: `/var/lib/openstreamer/`

| Шлях          | Що це                                                                                               |
| ------------- | --------------------------------------------------------------------------------------------------- |
| `recordings/` | Записи, якщо **Save to** не вказує на інше місце                                                    |
| `update/`     | `current.deb` і `previous.deb` — версії, між якими можна відкотитися, і журнал останнього оновлення |

USB-накопичувачі монтуються в `/media/`.

## У готовому образі: розділ даних

В образі `/etc/openstreamer` і `/var/lib/openstreamer` лежать на окремому розділі з
міткою `openstreamer`, змонтованому в `/data`. Їхні папки там, `config` і
`state`, під час кожного запуску підставляються за обома шляхами, тож шляхи
вище працюють так само.

Розділ відформатовано в ext4, тож Windows і macOS не прочитають його, якщо
вставити карту в комп'ютер.

## Мережа

Wi-Fi, Ethernet і WireGuard зберігаються як з'єднання NetworkManager з
назвами `openstreamer-ap`, `openstreamer-wifi`, `openstreamer-eth` і `openstreamer-wg`.

```sh
nmcli connection show
```

## Завантажувальний розділ: `/boot/firmware/`

- У `config.txt` з'являється секція між `# >>> openstreamer` і `# <<< openstreamer`,
  яка налаштовує порт USB-C для окулярів і дає відеоапаратурі достатньо
  пам'яті. Видалення Openstreamer прибирає її.
- Порожній файл `openstreamer-reset` тут скидає налаштування під час наступного
  запуску. Див. [резервна копія та скидання](/docs/maintenance/backup-and-reset).

## Журнали

```sh
openstreamer logs -f
```

Або через `journalctl -u openstreamer`. Див. [командний рядок](/docs/maintenance/command-line).
