Використовуй **Raspberry Pi OS Lite (64-біт, Debian 13 "Trixie")** на Raspberry Pi 4. Вимкни робочий стіл, що запускається під час завантаження, щоб дозволити вихід HDMI.

Публічного apt-репозиторію пакетів немає. Скопіюй наданий тестовий пакет `.deb` на Pi, відкрий термінал у цьому каталозі та виконай:

```sh
sudo apt install ./openstreamer_*.deb
```

Перезавантаж Pi, якщо потрібно, та відкрий `http://<hostname>.local` або IP-адресу Pi. Сумісна назва пакета й служби — `openstreamer`.

## Повторний запуск

Для іншої тестової збірки встанови її пакет `.deb` так само. Налаштування й записи зберігаються в `/var/lib/openstreamer`.

## Видалення

```sh
sudo apt remove openstreamer
```

`sudo apt purge openstreamer` також видаляє налаштування та пароль вебінтерфейсу. Перед видаленням пакетів збережи копію записів і налаштувань.
