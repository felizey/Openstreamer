Почни з [поширених проблем](/docs/help/common-issues). Якщо там немає
відповіді:

1. Пошукай помилку на сторінці **Logs** у вебінтерфейсі або виконай
   `openstreamer logs` через SSH.
2. Перевір, чи немає на сторінці **Performance** попередження про живлення.
3. Збережи версію з **System → About**, модель окулярів або камери, спосіб встановлення Openstreamer та відповідні рядки **Logs** для локального звіту про тестування.
