---
title: Вихід HDMI
description: Показуй відео на телевізорі, моніторі чи проєкторі.
order: 40
---


Підключи один або два екрани до або після запуску Pi. Типово обидва підключені micro-HDMI
показують однакове відео та заставку. У **Display → HDMI → HDMI ports** обери
**Both HDMI ports**, **HDMI 0** або **HDMI 1**. Відео декодується один раз;
поточний режим показано окремо для кожного екрана.

| Налаштування       | Що робить                                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| Show video on HDMI | Вимикай, коли нічого не підключено: це звільняє декодер і частину процесора для трансляцій.                                  |
| Resolution         | **Automatic** обирає прогресивний режим екрана до 1080p, близький до 60 Гц. Або обери стандартний ручний режим чи режим EDID. |
| Scaling            | **Fit** показує всю картинку, зі смугами, якщо пропорції різні. **Fill** заповнює екран і обрізає краї.                      |
| Rotate 180°        | Для екрана, встановленого догори дриґом.                                                                                     |
| Mirror             | Віддзеркалює картинку зліва направо.                                                                                         |

У списку завжди є 31 стандартний режим, навіть коли екран не визначено,
а також додаткові режими EDID. **p** означає прогресивну розгортку; **i** —
черезрядкову, з частотою в полях за секунду. 1080p60 і 1080i60 — різні режими.
Стандартні черезрядкові режими є для 1080, 576 і 480 рядків; 720p та 4K — прогресивні.
Примітка про пропорції використовує фізичні розміри EDID, які конвертер може передавати неправильно.

Роздільність застосовується до кожного екрана. Ручний режим запитує точні стандартні
таймінги, зокрема 1920 × 1080p при 60.00 Гц. Якщо режим відхилено, обери інший
або Automatic у вебінтерфейсі. Масштабування, поворот
і віддзеркалення діють на обидва виходи. Підключення HDMI перевіряються щосекунди; після зміни кабелів виходи переналаштовуються автоматично. Сумісний потік без IDR отримує новий стартовий кадр для декодера. Переналаштування може коротко перервати обидва виходи.

Поки відео немає, HDMI показує [заставку](/docs/using/splash-and-logo).
