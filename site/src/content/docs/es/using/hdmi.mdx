---
title: Salida HDMI
description: Muestra el vídeo en una TV, un monitor o un proyector.
order: 40
---


Conecta una o dos pantallas antes o después de iniciar la Pi. Por defecto, ambos puertos
micro-HDMI conectados muestran el mismo vídeo y pantalla de inicio. En
**Display → HDMI → HDMI ports**, elige **Both HDMI ports**, **HDMI 0** o **HDMI 1**.
El vídeo se decodifica una sola vez. El modo activo se muestra para cada pantalla.

| Ajuste             | Qué hace                                                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| Show video on HDMI | Desactívalo cuando no haya nada conectado: libera el decodificador y algo de CPU para el streaming.                                     |
| Resolution         | **Automatic** elige un modo progresivo hasta 1080p, cercano a 60 Hz. También puedes elegir un ajuste estándar o un modo que ofrezca la pantalla. |
| Scaling            | **Fit** muestra la imagen entera, con bandas si las proporciones no coinciden. **Fill** llena la pantalla y recorta los bordes.         |
| Rotate 180°        | Para una pantalla montada del revés.                                                                                                    |
| Mirror             | Voltea la imagen de izquierda a derecha.                                                                                                |

La lista siempre incluye 31 ajustes estándar, incluso sin pantalla detectada,
y añade los modos de EDID. **p** significa progresivo; **i**, entrelazado, con
la frecuencia indicada en campos por segundo. 1080p60 y 1080i60 son modos distintos.
Los ajustes entrelazados cubren 1080, 576 y 480 líneas; 720p y 4K son progresivos.
La nota sobre proporciones usa las dimensiones de EDID, que un conversor puede comunicar incorrectamente.

La resolución se aplica a cada pantalla. Un ajuste manual solicita el modo estándar
exacto, incluido 1920 × 1080p a 60.00 Hz. Si se rechaza, elige otro modo o Automatic
desde la web. Escala, rotación y espejo afectan a ambas.
Las conexiones HDMI se comprueban cada segundo y se reconfiguran automáticamente al cambiar cables. Un flujo compatible sin IDR recibe un nuevo fotograma inicial para el decodificador. La reconfiguración puede interrumpir brevemente ambas salidas.

Mientras no hay vídeo, el HDMI muestra la
[pantalla de inicio](/docs/using/splash-and-logo).
