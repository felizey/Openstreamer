The ready-made image is the easiest way in: Raspberry Pi OS Lite with
Openstreamer already installed and set up.

<Admonition type="warning">
  Flashing erases everything on the SD card, including the settings and any
  recordings already on it from an earlier install. Copy recordings off first,
  to a USB drive or by downloading them. To get a new version, [update from the
  web interface](/docs/maintenance/updates) instead: that keeps everything.
</Admonition>

## 1. Download

Use an image supplied with this build, if one is available. This local fork does not host public image downloads. For a test `.deb` package, follow [local package installation](/docs/getting-started/install-script).

## 2. Flash

**With Raspberry Pi Imager**

1. Open Raspberry Pi Imager and choose **Raspberry Pi 4** as the device.
2. For the operating system, scroll down to **Use custom** and pick the
   `.img.xz` file.
3. Choose the SD card and write it.

/>

**With balenaEtcher**

1. Choose **Flash from file** and pick the `.img.xz` file.
2. Choose the SD card and flash.

## 3. Boot

Put the card in the Pi, connect the goggles to the USB-C port, plug in an
HDMI screen if you have one, and power the Pi on.

Continue with the [first boot](/docs/getting-started/first-boot).
