Start with [common issues](/docs/help/common-issues). If it isn't there:

1. Look at the **Logs** page in the web interface for an error, or run
   `openstreamer logs` over SSH.
2. Check the **Performance** page for a power warning.
3. Save the version from **System → About**, your goggles or camera, how you installed Openstreamer, and the relevant lines from **Logs** for your local test report.
